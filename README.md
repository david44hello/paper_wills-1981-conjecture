# Wills' (1981) conjecture holds if and only if the dimension is at most 4

What is in this repository:

- [lean/](lean/) - the Lean 4 formalization: the deduction of Theorems 1.2, 1.3 and 7.1 and Corollary 1.4 from the paper's computations and the cited theorems. Its README lists what the proof takes as given and how to verify it.
- [wills-1981-conjecture/](wills-1981-conjecture/) - the programs and data for the paper's computations, and how to run them.
